# College Project: Cloud Resource Allocation (Java)
## 🎓 Student Project

This folder contains the **Java-based Implementation** of the Genetic Algorithm for Cloud Resource Scheduling. 
It is designed for academic submission, focusing on core algorithm logic and multi-threading.

### 📂 Folder Structure
*   **`src/`**: Contains all Java source files (`Main.java`, `GeneticAlgorithm.java`, etc).
*   **`docs/`**: Project Synopsis, Report, and Diagrams.
*   **`bin/`**: Compiled .class files (after you compile).

### 🚀 How to Run
1.  Open this folder in **Eclipse** or **IntelliJ IDEA**.
2.  Run `com.cloud.allocation.Main`.
3.  View the console output for generation-by-generation progress.

### ⚙️ Features
*   **Pure Java**: No external heavy libraries.
*   **Multi-threading**: Uses Java Threads for parallel evaluation.
*   **Console UI**: Simple text-based output for easy debugging.
