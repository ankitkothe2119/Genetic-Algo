# Commercial SaaS: Cloud Optimizer (Python + React)
## 💼 AI-Powered Resource Allocation System

This folder contains the source code for a **Commercial-Grade SaaS Product**. 
It uses a modern tech stack and advanced "AI Masala" (Hybrid GA+RL) for real-world cloud optimization.

### 📂 Folder Structure
*   **`backend_ai_engine/`**: Python FastAPI Service (The Brain 🧠). runs Genetic Algorithm + RL.
*   **`frontend_dashboard/`**: React.js Web App (The Face 💻). User Interface for clients.
*   **`api_layer/`**: Node.js API Gateway (The Guard 🛡️). Authenticates users.

### 🚀 How to Run
#### 1. Start Backend (Python)
```bash
cd backend_ai_engine
pip install -r requirements.txt
uvicorn main:app --reload
```

#### 2. Start Frontend (React)
```bash
cd frontend_dashboard
npm start
```
*   Open `http://localhost:3000` in your browser.
