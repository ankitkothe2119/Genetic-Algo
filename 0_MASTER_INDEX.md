# Genetic Algorithm for Cloud Resource Allocation
## Master Project Index

This project is divided into two distinct parts to serve both academic and commercial purposes.

### 📂 Project Structure

#### 1. [College Project (Java)](./1_College_Project_Java/)
*   **Purpose**: Academic Project, focused on core algorithms and multi-threading.
*   **Tech Stack**: Pure Java.
*   **Docs**: [Synopsis & Report](./1_College_Project_Java/docs/)

#### 2. [Commercial SaaS Product (Python + JS)](./2_Commercial_SaaS_PyJS/)
*   **Purpose**: Real-world Cloud Resource Allocation System (SaaS).
*   **Tech Stack**: Python (AI Engine), Node.js/FastAPI (API), React/JS (Dashboard).
*   **Features**: Hybrid GA+RL, Energy-Efficiency, Dynamic Scaling.
